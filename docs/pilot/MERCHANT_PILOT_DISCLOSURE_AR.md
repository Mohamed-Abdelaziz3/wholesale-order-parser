# إقرار تجربة التاجر التجريبية

هذه تجربة محدودة لمتجر واحد، وليست بديلاً عن نظام ERP كامل.

- النظام لا يتصل بواتساب حالياً. يتم نسخ نص الطلب من واتساب ولصقه يدوياً في النظام.
- قد يُرسل نص الطلب إلى Google Gemini فقط لاستخراج بنود الطلب. لذلك لا تُدخل بيانات شخصية لا نحتاجها للاختبار.
- Gemini يساعد في قراءة النص فقط. الصنف والكود والسعر والوحدة والكمية النهائية يجب أن يراجعها الموظف ويعتمدها بنفسه.
- إذا كانت مطابقة الصنف أو الوحدة غير مؤكدة، يجب مراجعتها وحلها بشرياً قبل اعتماد الطلب.
- المستند الناتج هو إذن صرف أو مستند تشغيلي، وليس فاتورة ضريبية.
- المنتج لا يرسل فاتورة إلكترونية إلى مصلحة الضرائب ولا يتصل بمنظومة الفاتورة الإلكترونية.
- الكتالوج وبيانات الطلب تخص هذا النشر المنفصل للتاجر، وليست مشتركة مع تاجر آخر.
- التجربة لا تدير المخزون حالياً.
- لا توجد في التجربة حالياً تكاملات ERP أو نظام دفع أو متابعة تلقائية عبر واتساب.

يرجى استخدام بيانات اختبار أو أقل قدر ممكن من بيانات العملاء، وعدم لصق كلمات مرور أو أرقام بطاقات أو بيانات شخصية غير لازمة.
